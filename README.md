## Remember that "Zero Trust is Mindset, not Toolset"
- The Story of the Zero Trust Concept:  [Hacking Google Series](https://www.youtube.com/playlist?list=PL590L5WQmH8dsxxz7ooJAgmijwOz0lh2H)
<br/><center>![img.png](img.png)</center>

- How to setup a Zero Trust Network Access Standard Model: https://cloud.google.com/beyondcorp <br/>
BeyondCorp is Google's implementation of the zero trust model. It builds upon a decade of experience at Google, combined with ideas and best practices from the community. By shifting access controls from the network perimeter to individual users, BeyondCorp enables secure work from virtually any location without the need for a traditional VPN.

- How to Measure Zero Trust Maturity: https://www.cisa.gov/sites/default/files/2023-04/CISA_Zero_Trust_Maturity_Model_Version_2_508c.pdf

<i>If you have read the documentation or have a good understanding of Zero Trust, you can start trying to implement and apply Zero Trust with ZTrust.</i>
